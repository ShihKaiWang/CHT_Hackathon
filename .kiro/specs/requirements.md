# 需求規格書 — 城市應變分析 AI Agent

## 產品願景

為交通指揮官提供一個 AI 驅動的即時決策平台，在突發事件發生後 60 秒內自動產出應變方案與多語通報，同時提供民眾友善的即時路況查詢介面。

---

## 使用者角色

| 角色 | 說明 | 權限 |
|------|------|------|
| 指揮官 | 交通管制中心決策者 | 完整系統存取、事件處置、通報發送 |
| 民眾 | 一般用路人 | 查看路況、路線規劃、語音播報、公眾回報 |

---

## 使用者故事與驗收標準

### US-1：即時路況監測

**As** 指揮官  
**I want** 看到即時車流量與飽和度  
**So that** 我能即時掌握路網壓力

**驗收標準：**
- [ ] 車流時序折線圖顯示 5 條路段即時數據
- [ ] 飽和度橫條圖標示正常/警告/危險三級
- [ ] 統計卡片顯示監測路段數、危險/警告路段數、最高飽和度
- [ ] 資料每秒隨模擬時鐘推進

### US-2：基地台信令人流分析

**As** 指揮官  
**I want** 監控基地台覆蓋區域的人流密度與漫遊率  
**So that** 我能判斷是否觸發多語通報

**驗收標準：**
- [ ] 人流時序圖顯示各站點用戶數
- [ ] 漫遊率圖表標示 30% 觸發線
- [ ] 超標站點高亮標示

### US-3：突發事件處置

**As** 指揮官  
**I want** 注入突發事件後自動獲得應變建議  
**So that** 我能在 60 秒內下達決策

**驗收標準：**
- [ ] 事件注入後自動分級（A/B 級）
- [ ] 自動計算 ETE（預估疏散時間）
- [ ] 產出替代路線與號誌調整方案
- [ ] 生成正式建議書文件

### US-4：AI Agent 主動巡邏

**As** 指揮官  
**I want** AI 自動掃描所有數據源並預判風險  
**So that** 問題發生前我就能收到預警

**驗收標準：**
- [ ] AI Agent 每 30 秒自動巡邏
- [ ] 偵測異常趨勢並產出預測性告警
- [ ] 顯示信心度與倒數時間
- [ ] 提供一鍵採納建議功能

### US-5：多語化通報發佈

**As** 指揮官  
**I want** 一鍵發送中/英/日/韓四語通報  
**So that** 外國旅客也能即時獲得交通資訊

**驗收標準：**
- [ ] 漫遊率 ≥ 30% 自動觸發四語模式
- [ ] 支援 6 管道預覽（簡訊/推播/廣播/看板/社群/LINE）
- [ ] 通報需 PIN 碼 + 5 秒倒數雙重確認
- [ ] Human-in-the-Loop：AI 建議需指揮官批准

### US-6：對話式策略諮詢

**As** 指揮官  
**I want** 用自然語言詢問系統建議  
**So that** 我能快速獲得 SOP 相關資訊

**驗收標準：**
- [ ] 支援 SOP 規則查詢
- [ ] 支援替代路線建議
- [ ] 支援 ETE 計算解釋
- [ ] 可切換本地規則引擎 / Bedrock RAG

### US-7：民眾即時路況

**As** 民眾  
**I want** 查看即時路況與替代路線  
**So that** 我能避開壅塞路段

**驗收標準：**
- [ ] 民眾模式無需密碼即可進入
- [ ] 顯示即時路況摘要
- [ ] 提供語音播報功能
- [ ] 支援公眾回報提交

### US-8：智慧出行規劃

**As** 民眾  
**I want** 獲得多模式交通建議（公車/捷運/YouBike）  
**So that** 我能選擇最佳替代方案

**驗收標準：**
- [ ] MaaS 路線規劃整合多種運具
- [ ] 共享運具即時庫存顯示
- [ ] 顯示預估到達時間

---

## 非功能需求

| 項目 | 要求 |
|------|------|
| 回應時間 | 事件處置 < 60 秒 |
| 安全性 | JWT 認證 + Rate Limiting + Audit Log |
| 可用性 | CloudFront + EC2，99% 正常運作 |
| 相容性 | Chrome/Edge 最新版，RWD 支援 |
| AI 安全 | Prompt Injection 過濾 + 降級模式 |
